# 💼 CV — Personal Portfolio / vCard Website

A complete **personal portfolio & CV website template** — profile, about, resume, portfolio gallery, blog cards and a contact section, with its own image assets.

## Open it
Open `index.html` in a browser — fully static, no build step.

## Structure
- `index.html` — the one-page vCard site
- `assets/css/style.css` — responsive styling (mobile + desktop)
- `assets/images/` — avatars, blog and project images

Use it as a starting point for your own online CV — change the text and photos and it's yours.
